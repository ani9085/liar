줄 간격 1.3(제목) ~ 1.5(본문). 설정에서 "아주 크게"를 고르면 전체 1.2배.

### 모양

- 모서리: 큰 카드 24dp, 버튼 20–22dp, 결과 상단 아래쪽 32dp, 배지 완전 둥글게
- 버튼 높이: 주 버튼 76–80dp, 보조 버튼 64–68dp, 전화 경고 버튼 132dp (최소 터치 영역 56dp 이상)
- 화면 여백: 좌우 20dp, 요소 사이 16–20dp
- 아이콘: 선 아이콘(stroke 2.2), 이모지 쓰지 않음. 결과는 색 + 아이콘 + 글자(위험/주의/안전)로 함께 구분
